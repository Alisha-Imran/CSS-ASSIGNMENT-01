# Personal Portfolio Website -CSS Assignment 01

Welcome to my first official Front-End Web Development assignment repository. This project is a single-page responsive portfolio website built completely from scratch using semantic layout architectures.

## Project Design Highlights
- Two-Column Fixed Layout: Features a permanently locked vertical navigation sidebar column and an independent, smooth-scrolling content canvas.
- Premium Dark Aesthetics: Engineered with a custom Black and Cadetblue high-contrast interface palette.
- Dynamic Icons Rows: Integrates a structured grid matrix of 12 monochrome web technologies and developer tools logos.
- Interactive Social Badges: Fully stylized Font Awesome brand icons that link directly to external profiles in a new browser tab.

## Technology Stack
- Structure: Semantic HTML5 Document Logic
- Styling: Custom CSS3 Layout Sheet (No external frameworks)
- Icons: Font Awesome Vector Library CDN
